# Arnav Jaiswal — Portfolio

Personal portfolio website showcasing my projects, skills, photography, and achievements.

**Live:** [ar9av.netlify.app](ar9av.netlify.app)

---

## Features

- **Animated hero** with typewriter effect and particle canvas background
- **Dark / Light theme** toggle with localStorage persistence
- **Projects** section with tech stack tags and links
- **Photography** gallery with lightbox viewer
- **Achievements & Certifications** showcase
- **Contact form** powered by Google Apps Script (no backend required)
- Smooth scroll-reveal animations and 3D hover effects
- Fully responsive across desktop, tablet, and mobile

## Tech Stack

| Layer | Tools |
| ----- | ----- |
| Markup | HTML5 |
| Styling | CSS3 (custom, no frameworks) |
| Scripting | Vanilla JavaScript |
| Form backend | Google Apps Script |
| Hosting | PythonAnywhere |

## Project Structure

```text
Portfolio/
├── index.html          # Main page
├── style/
│   └── style.css       # All styles
├── js/
│   └── script.js       # Interactions, particles, lightbox, form
└── assets/             # Images, resume PDF, favicon
```

## Running Locally

No build step needed — just open `index.html` in a browser:

```bash
# Option 1: direct file open
open Portfolio/index.html

# Option 2: live server (VS Code extension or any static server)
npx serve Portfolio
```
